# 手动选择要录制的软件或窗口

当前两个录屏场景都优先使用 `窗口捕获（手动选择）`，原来的 `屏幕捕获` 已保留但默认隐藏，方便临时回退。

## 选择一个软件

1. 先打开目标软件，并确保窗口没有最小化。
2. 在 OBS 中进入 `02 电脑录屏 + 真人小窗` 或 `03 电脑录屏全屏`。
3. 在“来源”面板双击 `窗口捕获（手动选择）`。
4. 在“窗口”下拉框里选择目标，例如 Edge、Chrome、PowerPoint、飞书或其他应用。
5. “捕获方式”先用“自动”；若黑屏，依次尝试“Windows 10”与 `BitBlt`。
6. 点击确定。这个来源在两个录屏场景中共享，选择一次即可。

## 切回整个屏幕

在来源列表中隐藏 `窗口捕获（手动选择）`，再显示 `屏幕捕获`。由于两者都已锁定并预设好尺寸，不需要重新拖动。

## 常见情况

- 最小化的窗口可能无法持续出图，录制时让目标软件保持打开。
- 某些开启硬件加速的软件出现黑屏时，可以先换捕获方式；仍不行再关闭该软件的硬件加速。
- 切换窗口不会改变圆形真人小窗、动态背景、音频轨道或缩放快捷键。
