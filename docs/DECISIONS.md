# 设计决策

## 为什么把“重点缩放”并入录屏场景

独立的“重点缩放”场景和缩放工具承担了同一件事，既增加场景数量，也让人需要判断该切场景还是按快捷键。现在只保留 `02 电脑录屏 + 真人小窗`，由 `Alt + Z` 在鼠标附近平滑放大或恢复软件来源；真人小窗、动态背景和品牌信息始终不动。`03 电脑录屏全屏` 继续承担最大可读面积的纯屏幕画面。

## 为什么场景快捷键使用连续数字

三个主场景固定使用 `Alt + 1/2/3`，顺序就是“人 → 带人讲解 → 纯屏幕”。`Alt + Z` 在鼠标附近放大或恢复，`Alt + F` 开关鼠标跟随，`Alt + R` 负责录制。所有高频动作都只需要一个修饰键，功能保留但按法更顺手。

## 为什么真人小窗不用纯白边框

纯白框在浅色网页上会失去边界，在深色网页上又显得突兀。新的圆框使用午夜蓝底色、冰蓝高光与少量冷紫过渡，既能保持分离度，也比绿色更百搭、更接近克制的科技感。

## 为什么动态背景不再整体漂移

整幅底图做缩放和平移时，观众会把运动理解为镜头晃动。现在底图完全固定，只把斜线视差、下方光带呼吸、上方柔光掠过和右下角圆环流光拆成独立层；每层幅度和节奏不同，但首尾参数一致，循环时既有生命感又不会抢内容。

## 为什么水波接近一秒

点击反馈既要被观众感知，又不能遮住操作目标。920ms 足够完成扩散，前 140ms 建立点击位置，后 780ms 持续淡出；配合缓出曲线，速度会自然减慢，不像警报灯或硬切动画。
