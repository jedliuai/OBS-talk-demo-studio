# 设计决策

## 为什么把“重点缩放”并入录屏场景

独立的“重点缩放”场景和缩放工具承担了同一件事，既增加场景数量，也让人需要判断该切场景还是按快捷键。现在只保留 `02 电脑录屏 + 真人小窗`，由 `Alt + Z` 在鼠标附近平滑放大或恢复软件来源；真人小窗、动态背景和品牌信息始终不动。`03 电脑录屏全屏` 继续承担最大可读面积的纯屏幕画面。

## 为什么场景快捷键使用连续数字

三个主场景固定使用 `Alt + 1/2/3`，顺序就是“人 → 带人讲解 → 纯屏幕”。`Alt + Z` 在鼠标附近放大或恢复，紧邻的 `Alt + X` 开关鼠标跟随，`Alt + R` 负责录制。原来的 `Alt + F` 会和浏览器功能冲突，因此不再使用。所有动作也同时出现在捕获排除的悬浮控制条上，不想记快捷键时可以直接点击。

## 为什么真人小窗不用纯白边框

纯白框在浅色网页上会失去边界，在深色网页上又显得突兀。新的圆框使用午夜蓝底色、冰蓝高光与少量冷紫过渡，既能保持分离度，也比绿色更百搭、更接近克制的科技感。

## 为什么动态背景不再整体漂移

整幅底图做缩放和平移时，观众会把运动理解为镜头晃动；幅度过小时，在 OBS 里又会看起来完全静止。现在底图完全固定，斜线在 22px 内漂移，光带独立呼吸，斜向柔光穿过画面，右下角半环则有沿路径移动的高光。每层幅度和节奏不同，但首尾参数一致，循环时既能被感知又不会像镜头晃动。

## 为什么背景只保留同心半环

底图自带的完整圆和真人边框如果圆心、直径不一致，会产生两个互相竞争的视觉中心。真人圆窗的实际圆心是 `(2250, 1110)`，因此背景完整圆被移除，只留下以同一圆心绘制、半径略大的渐隐半环。半环负责延伸构图，真人边框才是唯一完整主圆。

## 为什么水波放慢到约 1.3 秒

原来的水波面积偏小、消失偏快，不认真看容易错过。现在用 120ms 建立点击位置、90ms 短暂停留、1100ms 持续淡出，并把最大尺寸扩大到 3.35 倍；三层圆环依旧保持低透明度，能被注意到，但不会长时间遮住按钮和文字。

## 为什么光标增强只出现在 OBS 里

直接放大 Windows 系统光标会改变操作者的手感，也会影响日常使用。插件改为在 OBS 场景顶部叠加一个蓝白指针光环，并根据窗口客户区和场景绘制矩阵定位；观众看到更明确的鼠标焦点，操作者仍使用原来的系统光标。
