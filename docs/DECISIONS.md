# 设计决策

## 为什么删除“重点演示”场景

它与“电脑录屏全屏”的静态构图完全相同，区别只发生在讲解过程中。把它保留为独立场景会增加选择和记忆成本，也容易切错。因此重点演示被定义为一个瞬时状态：在录屏场景中按 `Alt + Z` 进入缩放，再按一次退出。

## 为什么只保留五个快捷键

高频操作只有切场景、强调和录制。鼠标跟随可以默认常开，暂停录制很少使用且误触代价高，所以不占全局快捷键。数字键负责“去哪里”，字母键负责“做什么”，形成稳定的记忆分组。

## 为什么真人小窗不用纯白边框

纯白框在浅色网页上会失去边界，在深色网页上又显得突兀。新的卡片使用低明度底色、柔和阴影与一条高饱和翡翠强调线，既能保持分离度，也能延续 Camo 风格的深绿科技感。

## 为什么水波接近一秒

点击反馈既要被观众感知，又不能遮住操作目标。920ms 足够完成扩散，前 140ms 建立点击位置，后 780ms 持续淡出；配合缓出曲线，速度会自然减慢，不像警报灯或硬切动画。
