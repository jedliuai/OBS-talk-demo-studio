# 设计决策

## 为什么恢复“重点缩放”场景

实际使用后发现，把重点缩放只做成临时快捷动作会让人缺少明确的场景反馈，也无法一眼确认当前是不是重点构图。因此恢复独立的 `03 重点缩放`：它完整继承 `02 电脑录屏 + 真人小窗` 的背景、圆形人像和品牌信息，只对软件画面做约 125% 的中心裁切放大。`04 电脑录屏全屏` 则继续承担最大可读面积的纯屏幕画面，两者用途不再重复。

## 为什么场景快捷键使用连续数字

四个主场景固定使用 `Alt + 1/2/3/4`，顺序就是“人 → 正常讲解 → 重点放大 → 纯屏幕”。缩放工具统一使用 `Ctrl + Alt`：`Z` 在鼠标附近放大或恢复，`F` 开关鼠标跟随；`Alt + R` 负责录制。这样功能完整，但记忆时只需区分“数字场景组”和“ZF 缩放组”。

## 为什么真人小窗不用纯白边框

纯白框在浅色网页上会失去边界，在深色网页上又显得突兀。新的卡片使用低明度底色、柔和阴影与一条高饱和翡翠强调线，既能保持分离度，也能延续 Camo 风格的深绿科技感。

## 为什么水波接近一秒

点击反馈既要被观众感知，又不能遮住操作目标。920ms 足够完成扩散，前 140ms 建立点击位置，后 780ms 持续淡出；配合缓出曲线，速度会自然减慢，不像警报灯或硬切动画。
