# 定型后的目录与维护方式

本地 OBS 相关文件已集中到工作区的 `OBS/OBS-talk-demo-studio/`，该目录就是 Git 仓库根目录。

| 目录 | 保留的内容 |
|---|---|
| `assets/` | 正式背景视频、背景图、圆形遮罩和边框 |
| `obs/` | 可公开的脱敏配置模板 |
| `scripts/` | 安装、备份、悬浮控制条脚本 |
| `plugin/`、`.github/` | Zoominator 补丁与可复现构建流程 |
| `motion-background/` | 背景动画源工程与依赖锁文件 |
| `docs/original-requests/` | 最初的两份需求，作为历史背景 |
| `worklog/` | 集中保留的中文工作总结 |
| `local-backups/` | 仅本地保留的初始备份、整理前备份和最终验证截图，不上传 GitHub |

2026-10-03 清理了背景工程的 `node_modules/`、`out/`、两版旧安装测试目录，以及已被最终验证截图替代的零散测试文件。清理内容移入 Windows 回收站，需要时可以恢复；回收站未清空前仍占磁盘空间。依赖与渲染输出本身也可重新生成。

OBS 的运行素材统一放在 `%APPDATA%\obs-studio\basic\assets\OBS-talk-demo-studio`，桌面 `OBS 控制条` 快捷方式指向整理后的脚本位置。后续更新素材时，还需要更新已安装的那一份。

历史文档可能记录已经替换的绿色主题、旧快捷键、旧目录或旧场景，不要据此覆盖当前配置。当前用法以 README 和最新功能文档为准。

后续修改完成验证后，在同一轮工作里提交并推送 GitHub。本机设备信息、密码、真实截图和录屏不随公开仓库同步。具体维护规则见根目录 `AGENTS.md`。
