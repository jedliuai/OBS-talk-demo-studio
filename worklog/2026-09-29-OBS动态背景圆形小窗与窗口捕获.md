# OBS 动态背景、圆形小窗与窗口捕获

## 1. 做了什么

把原来的翡翠品牌背景做成了 12 秒、2560×1440、30fps 的轻柔无缝循环视频，并把 Remotion 源工程一起放进 `OBS-talk-demo-studio`，以后想微调动效还能重新渲染。

在“电脑录屏 + 真人小窗”里新增了一个独立的摄像头近景场景：只在右下角小窗中放大并裁切人物，套上圆形遮罩、翡翠描边和很轻的光晕；真人全屏场景不受影响。

同时给录屏场景加入了共享的“窗口捕获（手动选择）”来源，当前选的是 Edge 演示窗口。原来的屏幕捕获保留但隐藏，需要时可以随时切回来。安装脚本、脱敏模板和中文文档也都同步更新了。

## 2. 为什么做

静态背景看久了有些僵，但动效太强又会抢内容，所以目标是让画面“有呼吸感”而不是让观众注意到动画本身。右下角摄像头如果直接缩小整张画面，人会显得太小，因此需要对小窗单独做近景裁切。窗口捕获则是为了避免全屏录制时把桌面通知、其他软件或无关内容一起录进去。

## 3. 值得记住的决策、坑或技术点

- 背景动画的缩放控制在约 0.7%，位移只有十几像素；循环首尾使用相同运动参数，首尾帧 SSIM 约 0.9965，肉眼不会感到跳变。
- 圆形人像不是破坏原摄像头源，而是通过“嵌套场景 + 独立遮罩”实现。这样右下角可以放大裁切，真人全屏仍保持原构图。
- 目前是固定中心近景，不是 AI 自动追脸。如果人在画面里移动很多，优先在 Camo 里开启 Auto Framing，再由 OBS 负责圆形裁切。
- Windows 窗口捕获有时刚启动会短暂显示空白；这次把捕获方法设为 Windows 10 后稳定工作。遇到黑屏可依次尝试“自动 → Windows 10 → BitBlt”，并避免把目标窗口最小化。
- 窗口捕获是两个录屏场景共享的同一个来源，所以改一次窗口，两边会一起更新。
- Remotion Studio 的应用内浏览器因为本机原生管道信任限制没能接入，但通过实际渲染关键帧、完整 MP4、FFprobe 和 OBS 重启后的现场画面完成了验证。

## 4. 一句话亮点

把一套“能录屏”的 OBS，升级成了会轻轻呼吸、会突出人物、还能只录指定软件的个人 IP 演示工作台。
