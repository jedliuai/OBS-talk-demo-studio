# 干净光标与点击反馈

## 做了什么

把 OBS 录制画面里的光标和点击效果整套重做，和前一天的死区跟随打进同一个插件版本（v1.6.0），管理员装一次 DLL 就都有了。

- 光标：不再在系统箭头上叠准星光环，改成只画一个干净的箭头。大小是系统箭头的 1.5 倍，白色填充、#111 细描边、圆角转折、向下约 3px 的柔和投影，用 4 倍超采样画出来，边缘很干净。位置加了约 60ms 的临界阻尼平滑，去掉抖动。
- 点击：箭头按下 60ms 缩到 0.86，松开约 180ms 弹回，中间轻微过冲到 1.06；点击点出现一次柔和扩散，灰蓝实心圆 13→30px、白色细环 24→42px，半秒内淡完。原来三圈蓝色雷达波、3.35 倍、1.3 秒那一套全部替换掉。
- 系统光标：新增「用干净的箭头替换系统光标」开关（`replace_system_cursor`，默认开）。插件只在自己画箭头时，才关掉它管理的窗口捕获、屏幕捕获的光标采集；关掉开关就恢复。

## 为什么做

用户原话是光标“太丑了”，点击之后的效果“也很差”。录出来的画面里系统箭头和 64px 准星光环挤在一起，点一下还要扩一秒多的三圈蓝波，像雷达，连续点击时圈套圈，反而把按钮盖住了。目标是 Screen Studio 那种干净、有手感的光标。

## 值得记住的决策、坑或技术点

- 系统光标的开关交给插件，而不是像最初计划那样手改本机场景文件。好处有三个：不用为了改 JSON 专门退出 OBS，也不会碰到摄像头和窗口选择；安装顺序不会出现“一个光标都没有”的空档（旧插件不动它，新插件加载后才切换）；开关一关系统光标就回来。模板里的捕获源保持采集光标，没装新插件也不会丢光标。
- 代价要写清楚：录制画面里 I 形光标、手形光标都会变成箭头。
- 箭头按左上角对齐、按箭尖缩放，按下回弹时箭尖不会漂。点击效果用真实点击坐标，不用平滑后的位置，否则涟漪会落在光标“追”过去的半路上。
- 点击效果两层的尺寸、时长不一样，没法用一张图缩放，所以拆成两个图层（实心圆、细环），各自带透明度滤镜。细环名字故意不用 “Zoominator Cursor Marker” 前缀，否则会被旧版遗留清理逻辑当垃圾删掉。
- 先用 Python 按同样的几何和颜色把浅色、深色背景各渲染了一遍。原方案在白底上偏淡，白环几乎看不见，于是实心圆起始透明度 0.26 → 0.32、细环深色描边 25% → 约 39%，深色背景上基本没变化。
- 坑：在 Git Bash 里用 `sed -i` 改上游源码会把 CRLF 悄悄变成 LF；Git Bash 的 grep 数 `\r` 也不准，要用 Python 读字节确认。
- 美术尺寸按 1080p 画布设计，按画布高度等比放大，1440p 画布下会自动变大一点。

## 一句话亮点

把录屏里“系统箭头 + 准星光环 + 三圈雷达波”换成一个干净的大白箭头：点下去会缩一下再弹回来，点击处轻轻荡开一圈，半秒就收。
