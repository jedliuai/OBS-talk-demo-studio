# 恢复重点缩放与精简快捷键

## 1. 做了什么

恢复了独立的 `03 重点缩放` 场景，并把原来的电脑录屏全屏顺延为 `04 电脑录屏全屏`。新的重点缩放不是纯全屏：它完整继承 `02 电脑录屏 + 真人小窗` 的动态背景、圆形人物、品牌签名和音频，只把被录制的软件画面做约 125% 的中心裁切放大。

四个主场景重新排成 `01 真人全屏 → 02 录屏 + 真人小窗 → 03 重点缩放 → 04 电脑录屏全屏`，快捷键对应 `Alt + 1/2/3/4`。

Zoominator 的两个必要功能也保留下来并重新分组：`Ctrl + Alt + Z` 在鼠标附近平滑放大或恢复，`Ctrl + Alt + F` 开关鼠标跟随。窗口捕获和备用屏幕捕获都加入了缩放来源。现场 OBS、脱敏模板、安装配置和中文文档全部同步更新。

## 2. 为什么做

之前为了减少重复场景，把重点演示合并成了一个缩放动作，但实际使用时缺少“我现在已经切到重点构图”的明确反馈。用户真正需要的是保留真人小窗布局，同时让软件内容更大，而不是另一个纯屏幕画面。

快捷键的问题也不是功能太多，而是没有形成清楚的记忆分组。因此这次不删缩放与跟随功能，只把场景统一放在数字组，把缩放统一放在 `Ctrl + Alt + Z/F` 组。

## 3. 值得记住的决策、坑或技术点

- `03` 直接复制 `02` 的全部八个场景元素，保证两者布局完全一致；窗口捕获左右各裁 256 像素、上下各裁约 137 像素，对应约 125% 的内容放大。
- 窗口捕获来源在 `02/03/04` 中共享，所以用户换一次软件，三个场景会同步更新。
- `Ctrl + Alt + Z` 不是只写进文档：已实际触发测试，窗口画面平滑进入 1.8 倍动态缩放，再按一次能够准确恢复到 `03` 原有的 125% 静态构图。
- Zoominator 原来只包含“屏幕捕获”，这会导致启用窗口捕获时快捷缩放没有目标；现在两个来源都包含，插件会处理当前可见的那个。
- OBS 关闭按钮会受托盘设置影响，看起来关闭但进程仍可能存在。修改插件配置后要确认进程真正重启，否则全局键盘钩子不会重新读取快捷键。

## 4. 一句话亮点

四个场景一条数字顺序，两个缩放动作一组 Z/F：功能一个不少，脑子却不用多记。
