# OBS 个人 IP 录制工作台

## 1. 做了什么

先盘点了本机 OBS 32.2.2、硬件、原有 Profile/Scene Collection 和 WebSocket 状态，启用了带密码认证的 obs-websocket。审核、安装并接入了 OBS MCP Server，验证了读取版本、Scene Collection、Scenes、Sources，以及创建 Scene、修改 Source、切换 Scene 的完整链路。

另外新建了独立的 `个人IP录制_1440p30` Profile 和 `个人IP录制工作台` Scene Collection，做了真人全屏、电脑录屏加真人小窗、重点演示、电脑录屏全屏四个正式场景，并通过 `00 音频总线` 统一管理主麦克风和系统声音。主麦克风加了 RNNoise、扩展器、压缩器和限幅器，录音轨分成混音、麦克风、系统声音三轨。

安装了 Zoominator 2.0.6，配置了鼠标附近的平滑缩放与点击光圈。最后完成了一次 37.67 秒真实录制，输出 2560×1440、30fps、NVENC H.264、三条 AAC 音轨的 Hybrid MP4，OBS 统计没有编码或渲染跳帧。

## 2. 为什么做

目标是把 OBS 变成打开就能录的固定工作台，录制时直接用快捷键切换真人、画中画、软件全屏和重点放大，让输出尽量接近成片，后面只在剪映里删口误、加字幕和做少量调整。

## 3. 值得记住的决策、坑或技术点

- 没有覆盖原来的 `未命名` 配置，而是新建独立 Profile 和 Scene Collection；旧配置也额外备份到了项目里的 `obs-backup/2026-09-29-before-template/`。
- MCP 选了维护较新的全协议分支，密码直接读取 OBS 本机配置，不复制进 Codex；同时限制了直播、任意协议转发和视频修剪等不需要的工具面。
- Zoominator 比旧 Lua 缩放脚本更适配 OBS 32，并且自带点击光圈，所以没有再启动 PowerToys，避免双重高亮和快捷键冲突。
- 本机目前没有检测到 DJI Mic；`主麦克风` 暂时绑定 Windows 默认输入，而当前实际解析为 `Microphone (Camo)`。连接 DJI 接收器并把它设为默认输入后，这个源会自动跟随；也可以之后改成固定设备 ID。
- Camo/iPhone 视频源已经放入所有需要人像的场景，但测试时只输出了 Camo 的未连接占位画面。正式录制前要先打开 Camo Studio 或连接实际摄像头。
- Advanced 输出使用 Hybrid MP4，兼顾崩溃恢复能力和剪辑兼容性；三条音轨分别是混音、麦克风和系统声音。

## 4. 一句话亮点

把 OBS 从“每次开录都要现搭”的工具，改造成了 1440p、三音轨、鼠标跟随放大、四场景一键切换的个人 IP 录制工作台。
