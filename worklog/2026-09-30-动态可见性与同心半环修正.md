# 动态可见性与同心半环修正

## 做了什么

重新制作了午夜蓝循环背景。先把底图右下角原来那个完整圆和光晕移除，再用 Remotion 画了一个与真人圆窗严格同心的渐隐半环。真人圆环仍然是唯一完整主圆，外面的半环只负责延伸构图，高光会沿半环缓慢移动。

同时把几组动效从“参数上在变、OBS 里看不出来”调整到肉眼可感知：斜线漂移提高到 22px，增加一束穿过画面的斜向柔光，上下光带使用不同节奏呼吸，半环的亮度和移动高光也分别变化。底图本身仍然完全不缩放、不位移。

## 为什么做

上一版虽然技术上有动画，但变化太弱，在真实 OBS 构图里又有大面积窗口内容遮挡，所以看起来和静态图一样。背景原有圆的圆心也没有和真人边框对齐，叠在一起像两个互相打架的圆。

## 值得记住的决策、坑或技术点

- 不要只在纯背景预览里判断动效，要放进最终 OBS 场景再看。窗口捕获会盖住大部分背景，动效必须在边缘和留白处仍然可见。
- 真人边框是 540×540，位置是 `(1980, 840)`，唯一正确圆心是 `(2250, 1110)`。背景半环直接以这个坐标为圆心，避免靠肉眼估位置。
- 半环选择在右侧和下侧展开，因为左侧大部分会被软件窗口遮住。它的两端用颜色和透明度渐隐，不再形成第二个完整圆。
- 动效是否真的可见可以用不同时刻的截图做 SSIM。最终 OBS 画面间隔 3 秒约为 0.983，已经明显有变化；Remotion 原始第 0 帧和第 359 帧为 1.000，循环首尾完全一致。
- OBS 的媒体源切换文件后可能继续播放旧缓存，修改视频后需要完整重启 OBS 才能看到新成片。
- 旧的完整圆底图和第一版循环视频已从当前版本移除，但仍能通过 Git 历史恢复。

## 一句话亮点

这次不是让背景“理论上会动”，而是让观众看得到光在呼吸，同时只留下一个真正的视觉圆心。
