# 珊瑚橙点击与点击音效

## 做了什么

v1.6.0 的干净光标用户很满意，这一版（v1.7.0）在它上面做了两件事：

- 点击圆圈换成珊瑚橙 #FF7A59。内层实心圆峰值透明度 0.26，外环改成 2.5px 珊瑚橙环、峰值 0.8，环内侧贴一圈 1px 白色高光；缩放和淡出曲线不变。
- 加了一声很轻的点击音效。约 40ms 的柔和「嗒」，峰值 -18 dBFS，由仓库里的脚本生成。鼠标按下时播放，只进录制的轨道 1（混音）和新增的轨道 4（单独的点击音轨），不监听，录的时候自己听不到。

配套改动：录制音轨从 1–3 扩到 1–4（模板 basic.ini 的 RecTracks 7 → 15），设置里加了「轻柔点击音效」开关和「点击音量」，安装脚本会把音效文件和语言文件一起装进 OBS 的插件数据目录。

## 为什么做

颜色是用户在四个方案里选的：中性灰能看清但没有性格；品牌蓝点在蓝色按钮上会消失；珊瑚橙和常见的蓝、绿界面反差最大。音效是为了「耳朵先知道点了」——观众不一定一直盯着鼠标。

## 值得记住的决策、坑或技术点

- 点击声要录进视频，又不能让自己在录制时听到：做成插件创建的媒体来源「Zoominator 点击音效」，放进隐藏的 `00 音频总线` 场景（三个展示场景都嵌了它），监听关闭，音轨只勾 1 和 4。媒体来源关掉了「激活时重新播放」，不然切到录屏场景时会凭空响一下。
- 发声条件和画箭头绑在一起：只有插件在画箭头、点击又落在捕获画面上才响。所以真人全屏场景、`Alt + Z` 这类快捷键、缩放手势都不会发声。
- 音效用标准库 Python 生成：正弦从约 2.1kHz 滑到 1.85kHz 再快速衰减，加一点低通噪声，余弦淡入淡出防爆音，固定随机种子，重跑得到逐字节相同的文件。ffmpeg 实测峰值 -18.0 dBFS、RMS -31.0 dB。
- WAV 不进补丁，由 CI 在构建时拷进插件 `data/sounds/`，打包进 Release；插件用模块数据路径找到它。
- C++ 源文件保持纯 ASCII：中文的来源名和场景名写成 UTF-8 字节转义，注释里也不放中文，免得 MSVC 在中文代码页下误读。
- 坑：在 bash heredoc 里给 Python 写 Windows 路径，`\a` 被当成响铃字符写进了工作流文件；之后改含反斜杠的文件一律用编辑工具或写独立脚本文件。
- 本机的 basic.ini 要等 OBS 退出后再改，否则 OBS 关闭时会把旧值写回去。

## 一句话亮点

录屏里的每次点击现在都有一圈珊瑚橙轻轻荡开，再配一声只录进视频、自己听不见的柔和「嗒」，后期还能单独把它关小。
