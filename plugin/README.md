# Zoominator 补丁：干净光标、点击反馈与音效、死区跟随

这个目录不复制上游仓库，只保存一个很小、可审计的补丁。

- 上游项目：`mmlTools/zoominator`
- 基准版本：`2.0.6`
- 基准提交：`23ea8397023506ae047948189c6c22018d7f5843`
- 许可：GPL-2.0

补丁会按实际捕获窗口客户区和 OBS 场景变换矩阵校正坐标。录制画面里的系统光标换成一个干净箭头：系统箭头的 1.5 倍，白色填充、#111 细描边、柔和投影，4 倍超采样绘制，约 60ms 平滑去抖；插件只在画箭头时关闭所管理捕获源的光标采集（`replace_system_cursor`，默认开启，关掉即恢复系统光标），不会修改操作者的 Windows 系统光标。点击时箭头按下缩到 0.86、松开弹回并轻微过冲到 1.06，点击点出现一次约 0.5 秒的柔和扩散：珊瑚橙 #FF7A59 实心圆 13→30px，加 2.5px 珊瑚橙细环（内侧 1px 白色高光）24→42px。按下鼠标时还会录进一声很轻的点击音效（`click_sound`，默认开启；`click_sound_volume_db`，默认 0），由插件创建的「Zoominator 点击音效」媒体来源播放，放在隐藏的 `00 音频总线` 场景里，只进轨道 1 和轨道 4，不监听。音效文件 `assets/sounds/zoominator-click.wav` 由 `scripts/make_click_sound.py` 生成，CI 构建时打包进插件数据目录 `sounds/`。放大后的鼠标跟随改为「死区跟随」：鼠标在可视区域中间的安全框（`follow_deadzone_pct`，默认 60%）内移动时画面不动，进入边缘带后用临界阻尼弹簧（`follow_spring_ms`，默认 450ms）平移到刚好让鼠标回到安全框内；暂停或恢复跟随时锚点保持连续，不再跳变。设为 0 可回到上游的连续平滑跟随。GitHub Actions 每次都从固定标签拉取官方源码、应用补丁并构建，以便审计和复现。

补丁还注册了 `zoominator.toggle_zoom` 与 `zoominator.toggle_follow` 两个 OBS 内部动作，让悬浮控制条可以经本机 WebSocket 可靠触发缩放和跟随，不受 Windows 权限级别或模拟按键拦截影响。实体键盘上的 `Alt + Z` / `Alt + X` 仍然保留。
